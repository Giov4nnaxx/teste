# 🍔 Sistema de Gestão de Cantina

Sistema desktop desenvolvido em C# com Windows Forms para gerenciamento de vendas, controle de estoque e organização de pedidos em uma cantina.

---

## 💻 Tecnologias
- C#
- .NET (Windows Forms)

---

## 🚀 Funcionalidades
- Realização de vendas com cálculo automático de troco  
- Controle de estoque com atualização automática  
- Sistema de login com diferentes perfis (Admin, Balcão e Cozinha)  
- Separação de funcionalidades por tipo de usuário  
- Visualização e controle de pedidos pela cozinha  
- Exibição de pedidos prontos para retirada  
- Validação de dados para evitar inconsistências  

---

## 🔐 Perfis de usuário
- **Admin (Cantineiro):** acesso total ao sistema  
- **Balcão:** realiza vendas e chama pedidos  
- **Cozinha:** gerencia preparo dos pedidos  

---

## 🧠 Regras de negócio
- Não permite estoque negativo  
- Itens vendidos são automaticamente baixados do estoque  
- Cozinha visualiza apenas itens que exigem preparo  
- Sistema calcula troco automaticamente  

---

## 🎯 Objetivo
Projeto desenvolvido com base em levantamento de requisitos, simulando um sistema real de vendas com foco em regras de negócio e organização de processos.

---
